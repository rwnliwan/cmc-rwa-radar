RWA Radar Tokenised-Equities Screener & Issuer-Spread Monitor

Built on the CoinMarketCap RWA API (/v5/real-world-assets/). Read-only: this page shows a snapshot written by cmc_run.py — it never calls the API itself.

Monitor status only — not investment advice. Decisions use the robust spread (IQR/median): an asset is flagged when its robust spread exceeds 0.5%. The 0.5% threshold is an exploratory heuristic chosen after inspecting one top-25 snapshot with 23 covered assets. It is not a statistically validated anomaly threshold, risk score or trading signal. The Spread column is the reported max–min spread; the Robust column is the decision metric. The Tokens column shows priced-token count / distinct issuer count — the metric is cross-token dispersion, token-weighted, not issuer-balanced.
